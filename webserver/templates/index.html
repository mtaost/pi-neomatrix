Ambient automation

When enabled, the BH1750 light sensor can dim the display as the room gets darker and pause it when the room stays dark.

Turning this off leaves the display at the brightness chosen on the Display page and prevents automatic sleeping. When presence standby is enabled, this sensor still dims the display but does not put it to sleep.

Presence standby

The MLX90640 thermal camera can pause the active display when a person is no longer detected, then wake it when someone returns.

The detector keeps running while the display is asleep. It is disabled by default and stores only the latest in-memory frame.
